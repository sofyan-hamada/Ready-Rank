# دليل تشغيل وتهيئة موقع "Ready Rank" 🎮

موقع **Ready Rank** هو منصة حديثة لبيع حسابات الألعاب المصنفة الجاهزة للعب (Ranked Accounts) مع نظام تقييمات للخدمة، ولوحة تحكم متكاملة للمالك لإدارة الأسعار، المخزون، الطلبات، والتقييمات.

الموقع مبني باستخدام تقنيات:
- **Next.js (App Router)**
- **Tailwind CSS**
- **Supabase** (لقاعدة البيانات، المصادقة وتخزين الحسابات) مع إمكانية التشغيل التجريبي المحلي (Offline-first Fallback) في حال عدم توفر الاتصال بـ Supabase.

---

## 📌 المتطلبات الأساسية
تأكد من تثبيت البرامج التالية على جهازك:
1. **Node.js** (الإصدار 18.0 أو أحدث)
2. **NPM** (يأتي مدمجاً مع Node.js)
3. حساب على **Supabase** (لتشغيل قاعدة البيانات الحقيقية والربط الفعلي)

---

## 🛠️ الخطوة 1: التشغيل والتشغيل المحلي (Local Development)

### 1. تثبيت الحزم والمكتبات المعتمدة
افتح مبدل الأوامر (Terminal) في مجلد المشروع الرئيسي، وقم بتشغيل الأمر التالي لتثبيت جميع الاعتمادات:
```bash
npm install
```

### 2. تشغيل خادم التطوير المحلي
لتشغيل الموقع محلياً على جهازك في بيئة التطوير، اكتب الأمر التالي:
```bash
npm run dev
```
بشكل افتراضي، سيتم تشغيل الموقع على الرابط: [http://localhost:3000](http://localhost:3000)
*(ملاحظة: إذا كان المنفذ 3000 مشغولاً، سيقوم الخادم تلقائياً بالتحويل إلى المنفذ 3001: [http://localhost:3001](http://localhost:3001)).*

> [!TIP]
> **وضع التشغيل التجريبي المحلي (Offline Mode)**
> يعمل الموقع تلقائياً في وضع التشغيل التجريبي ويحفظ البيانات في الذاكرة المحلية للمتصفح (`localStorage`) إذا لم تقم بربط قاعدة بيانات Supabase. هذا يعني أنه يمكنك اختبار عمليات الشراء ولوحة التحكم وإضافة الحسابات فوراً دون الحاجة لإعداد قاعدة بيانات في البداية!

## 🗄️ الخطوة 2: إعداد قاعدة البيانات والربط الفعلي مع Supabase

لتفعيل الربط الحقيقي وحفظ الحسابات والطلبات بشكل دائم عبر السحابة:

### 1. إنشاء مشروع جديد في Supabase
1. اذهب إلى موقع [Supabase](https://supabase.com) وأنشئ حساباً مجانياً.
2. قم بإنشاء مشروع جديد (New Project) واختر اسماً وكلمة مرور للمشروع وحدد المنطقة الأقرب لك.

### 2. تشغيل ملف قاعدة البيانات (SQL Schema)
1. في لوحة تحكم Supabase الخاصة بمشروعك، اذهب إلى قسم **SQL Editor** من القائمة الجانبية.
2. انقر على **New query** (استعلام جديد).
3. افتح ملف [supabase_schema.sql](file:///c:/Users/MoNaser/Desktop/Sofyan/supabase_schema.sql) الموجود في مجلد المشروع الرئيسي، وقم بنسخ محتوياته بالكامل ولصقها في محرر SQL في Supabase.
4. انقر على زر **Run** في الزاوية لتنفيذ الاستعلام. سيقوم هذا تلقائياً بإنشاء جداول (الأسعار، المخزون، الطلبات، والتقييمات) وتفعيل الحماية ووضع البيانات الأولية للألعاب الخمسة.

### 3. ربط مفاتيح الاتصال بالمشروع
1. في لوحة تحكم Supabase، اذهب إلى **Project Settings** (إعدادات المشروع) ثم إلى قسم **API**.
2. ابحث عن المفاتيح التالية:
   - **Project URL** (رابط المشروع)
   - **anon public** (مفتاح anon العام)
3. في المجلد الرئيسي لمشروعك، أنشئ ملفاً جديداً باسم `.env.local` وضع فيه المتغيرات التالية مع تعويض القيم الخاصة بك:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=رابط_مشروعك_هنا
   NEXT_PUBLIC_SUPABASE_ANON_KEY=مفتاح_anon_الخاص_بك_هنا
   ```
4. أعد تشغيل خادم التطوير (`npm run dev`) وسيتعرف النظام تلقائياً على الاتصال ويقوم بالتحول من وضع التخزين المحلي إلى قاعدة بيانات Supabase السحابية الحقيقية!

## 🚀 الخطوة 3: رفع الموقع على الإنترنت (Go Live / Deploy)

الطريقة الأسهل والأفضل لرفع تطبيق Next.js على الإنترنت هي منصة **Vercel** (المنصة الرسمية المطورة لـ Next.js):

### 1. رفع الكود على GitHub
1. قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub (اجعله خاصاً Private أو عاماً Public).
2. ارفع كود المشروع إلى المستودع.
*(ملاحظة: ملف `.env.local` لن يتم رفعه لأنه مدرج في ملف `.gitignore` لحماية معلومات قاعدة بياناتك).*

### 2. الرفع المباشر عبر Vercel
1. اذهب إلى [Vercel](https://vercel.com) وسجل الدخول باستخدام حسابك في GitHub.
2. انقر على زر **Add New** ثم اختر **Project**.
3. قم باستيراد (Import) مستودع كود Ready Rank من قائمة مستودعات GitHub الخاصة بك.
4. قبل الضغط على زر Deploy، افتح قسم **Environment Variables** وقم بإضافة المتغيرين التاليين (بنفس القيم التي استخدمتها محلياً):
   - اسم المتغير الأول: `NEXT_PUBLIC_SUPABASE_URL` | قيمته: رابط مشروعك في Supabase.
   - اسم المتغير الثاني: `NEXT_PUBLIC_SUPABASE_ANON_KEY` | قيمته: مفتاح anon العام لمشروعك.
5. انقر على زر **Deploy**.
6. في غضون دقيقة واحدة، سيكون موقعك جاهزاً ومتاحاً للجميع برابط عام مجاني (مثل `ready-rank.vercel.app`)!

## 🔐 لوحة تحكم المدير (Admin Dashboard)
- **رابط الدخول**: اذهب إلى الرابط `/admin` في موقعك.
- **بيانات الدخول الافتراضية**:
  - البريد الإلكتروني: `admin@readyrank.com`
  - كلمة المرور: يمكنك إدخال أي كلمة مرور في وضع التطوير المحلي أو وضع التشغيل التجريبي لتسجيل الدخول الفوري.

### وظائف لوحة التحكم:
1. **تعديل الأسعار**: حدد السعر بالجنيه المصري (EGP) لأي من الألعاب الخمسة وسيتم تحديثه فوراً في الصفحة الرئيسية للمشترين.
2. **شحن المخزون (Inventory Loader)**: يمكنك كتابة بيانات اعتماد الحسابات الجديدة (مثل: `username:password`) وتخزينها، وسيقوم النظام بتسليمها آلياً للمشتري بمجرد الدفع.
3. **سجل الطلبات الحية**: يظهر إشعار فوري وتنبيه صوتي (Synth Bell Sound) عند قيام أي مستخدم بعملية شراء جديدة يوضح تفاصيل اللعبة والكمية المطلوبة.
4. **إدارة المراجعات**: يمكنك قراءة مراجعات العملاء وحذف أي مراجعة غير مرغوب فيها.
